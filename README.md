# 文匠 AI · 二创工作台

把一条链接、一个热点，写成你自己的稿。移动端优先的二创工作台：从选题、取正文，到改写、原创、配图、归档，一条链路走完。

纯前端单文件应用，`index.html` 自包含，双击即可打开，也可部署到 GitHub Pages 添加到主屏幕当 App 用。当前版本 v2.21.0。

## 快速开始

只需要一个 `index.html` 就能跑。三种方式，按省事程度排：

| 方式 | 适合谁 | 步骤 |
| --- | --- | --- |
| 网页上传 | 只想自己用、没有命令行基础 | 传 5 个文件到新建仓库，开 Pages，一分钟上线 |
| 一条命令 | 有 GitHub token | `GH_TOKEN=xxx node scripts/deploy.mjs`，自动建仓库、推送、开 Pages |
| 整仓库部署 | 想要热榜自动刷新 | 推完整仓库，Action 每 15 分钟抓一次热榜 |

网页上传只需这 5 个文件（都在仓库根目录）：`index.html`（必需）、`manifest.webmanifest`、`sw.js`、`icon.svg`、`icon-512.png`。上传到仓库后，Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存，约一分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

一条命令部署用 fine-grained token，只勾这一个仓库，权限给 Contents、Pages、Workflows 的读写，有效期 7 天。可选环境变量：`REPO`、`VISIBILITY=private`、`SKIP_WORKFLOW=1`、`DRY=1`。

装到手机：iOS Safari 或安卓 Chrome 打开线上地址 → 分享 → 添加到主屏幕，就是一个全屏、无地址栏、断网也能开的 App（入口也在「我的 → 装到主屏幕」）。只传 `index.html` 时没有离线缓存，但仍可添加到主屏幕。

本地开发：`node build.mjs && node server.js`，访问 `http://localhost:3000`。改完 `src/` 或 `assets/` 里的文件，记得跑一次 `node build.mjs` 重新生成 `index.html`。本地自带后端时，热榜和解析走同源 `/api/health`、`/api/hot`、`/api/parse`，没有跨域问题。

## 功能一览

首页只有 6 个入口，热榜从底部导航进入。六个功能分别是：

- **接任务原创**：贴一条活动帖，拆成任务、联网取证、自己写稿。
- **链接二创**：贴任意链接或正文，取原文后改写成多平台稿件。
- **文案改写**：直接粘贴一段文字改写。
- **双素材融合**：把两篇素材合成一篇。
- **写条评论**：贴链接或正文，直接生成读者评论。
- **实时热榜**：底部导航进入，看各平台当下热搜并直接拿来写。

外观三档：跟随系统 / 深色 / 浅色，默认跟随系统。入口在「我的 → 外观」，右上角图标也可直进。

## 实时热榜

热榜走的是各平台当下的实时接口，不造假、不用编造内容填充。

- **真实数据源**：当前接通 10 个平台：微博、知乎、头条、百度、抖音、B站、36氪、少数派、IT之家、极客公园。数据源构成：codelife（`api.codelife.cc`，国内直连、免 Key、实时）提供微博、知乎、抖音、百度、B站、36氪、IT之家 7 个，头条走 60s / codelife，少数派走官方 API，极客公园走官方 RSS。
- **多平台聚合**：选中某个平台看完整榜单，下方「其他平台实时榜」把其余平台各取前 6 条并列展示，带平台名、热度、抓取时间，点标题直接拿去写。实测一屏内 10 个平台实时话题。
- **抓不到就说抓不到**：小红书目前没有免费、国内直连、免自建的公开榜单接口，所以不编造数据填充。
- **实时优先、缓存兜底**：每 60 秒自动刷新，时间戳精确到秒；只有全部通道失败时才读缓存，并明确标注「缓存 · X 分钟前」，不会拿旧数据冒充实时。
- **内容过滤**：时政、军事、外交类条目不进入榜单（不适合二创），页面会写明过滤了多少条。
- **抓不到就说抓不到**：例如小红书目前没有免费、国内直连、免自建的公开榜单接口，所以不会编造数据填进去。站内 12 篇示例素材一律标注「示例素材 · 非真实新闻」。

## 链接二创与正文解析

在「链接二创」页贴入链接，点「先解析看看」，App 会自动抓回标题和正文。开箱即用，不需要配置任何东西。

**内置免费解析节点。** App 内置了一个免费、国内可直连的公共解析节点，粘贴链接即可自动抓正文（含公众号），实测一秒左右返回上千字。这是纯前端能做到的关键——浏览器跨域读不了别人的网页，必须有一台服务器代抓，这个节点就是那台服务器。它带 CORS 头、手机浏览器可直接调用，不花钱、不用登录、不用翻墙。

**可选的自建服务。** 想用更稳的自家服务，可在「我的 → 解析服务」填自己的地址，填了就优先用你的；点「清空地址」会恢复内置节点。仓库 `worker/` 里有一份零依赖的 Cloudflare Worker 可作参考，但 `*.workers.dev` 默认域名在国内被按域名阻断，自建需绑自己的域名，详见 `worker/README.md`。

**直接粘全文。** 遇到少数抓不到的站点，长按复制正文，进「文案改写」直接粘进来，改写效果完全一样。

解析服务只认一个极简契约：`GET /api/health` 返回 `{ok:true}`，`GET /api/parse?url=` 返回 `{ok,title,text}`。任何符合这个契约的接口都能填进去。

说明：早期版本尝试过「打开原文 → 复制 → 切回来自动读回」的路径，但浏览器普遍限制网页读取剪贴板，实测不可用，已在 v2.23 移除。现在统一走内置解析节点，抓不到就直接粘全文。

## 内容创作：接任务，写原创

底部导航「创作」走的是和「改写」完全不同的路：改写是把别人的稿子重排，创作是先把任务读懂、再去联网找素材、然后自己写。不换同义词，也不编数字。

关键在「读懂任务」这一步——不是照字面抽字段，而是像人读阅读理解那样理解帖子。比如活动里出现 NoSpend、断舍离、City Walk 这类概念，不会只按字面硬解，而是结合常识解释它到底指什么行为、主办方真正想要什么内容、一个真人怎么写才算合格。这个理解会一路带到写稿环节，所以成稿不会退回"字面执行"的生硬腔调。AI 连不上时，内置一份常见概念的常识词库兜底，理解不会退化成机械拼标题。

流程五步：贴活动帖（读不到就给「粘贴正文」入口）→ 拆任务并自动研究：本地稳稳提取「参与方式 / 截止时间 / 话题 / 奖项 / 硬性要求」，AI 负责理解任务、列出「要弄懂的概念」和「联网研究的问题」，接着立刻用这些问题去查资料（搜的是"概念怎么回事、真人怎么做、去哪找素材"，不是把活动名再搜一遍），结果直接带进下一步 → 确认任务（参与方式可多选、可手动改，并展示"我读明白了什么"）→ 写原创（模型只拿到勾选资料 + 你的素材 + 任务理解，提示词写死"数字日期能在资料里找到、不连续照搬 12 字、没亲历就写"我看到的""，并要求像真人一样表达）→ 成稿核对（逐句标注来源、数字单独标出、发布清单自动勾选）。

联网素材来自公共检索通道（bing + 搜狗），质量参差不齐，所以每条都算相关度、默认只勾较相关的，交给你判断；搜不到也不卡住——原帖全文已在资料池里可直接核对。

读图：压缩到 1024px 交给识图模型描述场景与文字，当作「我拍的这张图里有什么」；没有识图模型时图片只作配图。读视频：浏览器抽 4 帧逐帧识图，不上传原视频、不做语音转写，没有字幕就如实说明「只有作者文案」。

三条底线：不编造数字与亲历细节、不整段照搬资料、不承诺收益与绝对化说法。查不到资料时界面会让你贴链接或只用素材写，而不是让模型硬编。

## 文案改写与配图

改写支持 6 种风格 × 3 档强度 × 10 个平台（头条、百家号、公众号、小红书、抖音、知乎、酷安、网易小蜜蜂、B站专栏、微博），每个平台是独立的读者、结构、语气、禁忌配置，不是只改字数。写完本机自检篇幅、结构、长句和套话，不合格自动重写。

字数由你定：跟原文（默认）、600 / 1200 / 2000 / 3000 字。平台区间只作提示，长稿不会被强行压成摘要；原文撑不起所选字数时会写明「原文只够 X 字」，不注水、不编造。

配图优先用原文里的真实图片（按文件去重、滤掉 1px 占位图），点「设为封面」直接进成稿；确实没有可用图才用出图模型生成，或给三张提示词（竖版封面 / 横版头图 / 方图细节，三个不同机位）复制到即梦、豆包、MJ。出图前从正文抠出具体实物和场景（中英双版 + 机位参数），有识图模型时生成后自动核对，跑偏就重画一次。

写评论有两条路：成稿页点「读者会怎么评」生成 3 条模拟评论；或首页「写条评论」贴链接直接出 2/4/6 条，分真诚、犀利、补充内情三种口气。

## 模型配置

可以接多家服务商，每家填 Base URL + Key，点「连接并获取可用模型」拉取列表。内置 11 家常用服务商一键填地址（智谱、百炼、火山方舟、NVIDIA、OpenRouter 等），只填域名也会按厂商自动补齐路径。

- **内置免费通道**：Pollinations 与 LLM7 免 Key、允许浏览器直连，没接任何服务商时一键启用即可出稿。
- **连通性分批测**：拉完列表只自动试 6 个，工具栏每次测 20 个未测的，随时可停；每个模型要真写一句中文，写不出成句的自动剔除。免费清单可从 GitHub raw 拉取更新（jsDelivr 兜底）。
- **直连与中转**：服务商卡片上标注浏览器能否直连（DeepSeek、硅基流动、百炼、Kimi、内置免费可用；智谱、OpenAI、NVIDIA 需中转）。直连失败自动走自建服务的 `/api/llm` 中转，Key 只在单次请求里带上。
- **故障转移**：设一个默认服务商，其余按添加顺序排队；默认那家超时、限流或 Key 失效就自动换下一家，全都调不通才退回本机引擎。

## 部署详解

两套彼此独立的部署，别搞混：GitHub Pages 托管整个 App（打不开就没 App 了）；Cloudflare Worker 只托管解析接口（App 能开，但没有自建解析时只能走上面三条路径，成功率低）。Worker 页面打开是一片 JSON 或说明页属于正常现象。

单文件部署出来的站点热榜显示为「快照」（内联那份，页面标出抓取时间）；联网正常时先试实时接口，成功就显示「实时」。整仓库部署时，Action 每 15 分钟刷新 `data/hot.json`，首次部署后去 Actions 页手动跑一次 `refresh-hot`。

白屏问题已不存在：`index.html` 是构建产物、自包含，不再依赖同目录 `assets/`；万一真白屏，页面 2.5 秒后会自己提示原因。

本地长期跑可用 pm2 守护：

```bash
npm i -g pm2
PORT=3000 pm2 start server.js --name wenjiang
pm2 save
```

## 关于原创度

没有做「原创度评分」这种无法验证的东西，页面上是两个可核对的数字：改写幅度（输出里连续 12 字以上片段与原文不重合的比例）和重合率（这些重合片段占全文的比例）。同一套算法算出，加起来是 100，和平台判定不是一回事。

本机引擎是规则驱动的，短稿能做到 60–90% 幅度，长稿明显偏低——界面会直接建议「长文接模型」。接了大模型走 AI 路径时，改写幅度由模型决定。

## 合规边界

不承诺「过原创检测」，不做同义词替换式洗稿营销。AI 生成内容默认在复制时附带声明（可在「我的」关闭），对应 2025 年 9 月施行的《人工智能生成合成内容标识办法》。深度改写指重排结构、换视角、补信息，不是改几个词。素材和 Key 只存在浏览器 localStorage，仓库里没有任何密钥。
